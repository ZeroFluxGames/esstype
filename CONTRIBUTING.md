# Katkı

1. `npm install` ile bağımlılıkları kur.
2. Kaynak kod `src/` içinde; düz JavaScript ve CSS, derleyici gerekmez.
3. `npm run build` → `dist/esstype.html` (tek dosya, çevrimdışı çalışır).
4. `npm start` → http://localhost:5173 üzerinde dene.

Modüller: `core` (veri, tema, kenar çubuğu) · `layout` (sayfa motoru) · `editor` (yazı düzenleyici) ·
`objects` (serbest nesneler, çizim) · `present` (slayt temaları, geçişler) · `show` (slayt gösterisi, sunucu görünümü) ·
`deck` (sunum düzenleyici) · `export` (PDF/Word/PowerPoint…) · `app` (açılış, şablonlar, ayarlar).
